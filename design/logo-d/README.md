# design/logo-d — 实心 D（右侧渐变模糊）候选集 v1（2026-10-08）

## 是什么

白底 **实心 D + 右侧横向渐变模糊** 方向的 logo 候选：纯矢量、确定性渲染（无随机种子）。方向来自用户给的参考图（参考图角上带 ™ 标记——若它来自既有品牌标识，1:1 复刻会带 `docs/BRANDING.md` §4 同类商标问题，对外分发前按那条纪律评估）。

与 `../logo/`（已定稿的黑底反白鲸鱼）、`../logo-triangle/`（倒三角候选）并列的**提案集，尚未定稿**；用户选定后再收口进 `docs/BRANDING.md`。

| 文件 | 作用 |
|---|---|
| `index.html` | **唯一事实源**：几何与模糊配方 + 设计稿板 + 导出按钮（自包含，双击即开） |
| `exports/` | 产物：3 个变体各一份 1024 PNG + SVG，基准变体另有 512…16 尺寸阶梯 PNG |

## 配方

画布 1024（viewBox），白 `#FFFFFF` 铺底，D 取 `#0b0b0c`（与品牌黑同值）。改 `index.html` 顶部常量即改全部产物。

**实心 D 轮廓**（照参考图实测）：左侧矩形柄 + 右侧半圆，半径 = 高/2，无字腔；高 = 72% 画布（737.28px），宽/高 = 0.977（柄 0.477 + 半圆 0.5 → 宽 720.34px）。左侧两角圆角 = 高 10%（按用户要求加的；参考图本身是硬角，别照参考图改回直角）。1024 画布里落位：左缘 x 121.4、上缘 y 143.36、实心右缘 x 841.7。

**右侧渐变模糊**：不是整块模糊，是随 x 增强的横向渐进模糊——实心宽度方向划 64 条互不重叠的横向条带，第 i 条带用 σ = σmax·(i+1)/64，条带内 σ 恒定；起模糊处左侧仍是实心原形。

| 变体 | 实心右缘处 σ / 高 | 起模糊处 / 实心宽 | σmax / 高 |
|---|---|---|---|
| `fade` 基准（照参考图） | 0.055 | 0.42 | 0.060 |
| `fade-soft` 柔 | 0.075 | 0.34 | 0.081 |
| `fade-tight` 紧 | 0.032 | 0.55 | 0.035 |

**定位**：按各变体自身的视觉外框（实心右缘 + 1.5σ）水平居中；D 高 72% 画布，垂直居中。

两条实现约束（改这块前先读，都是像素自证抓到的）：

- **滤镜区域要显式覆盖整幅画布**。默认区域按元素 bbox 取，会把模糊外溢裁断——表现是右缘看着像硬边、尾巴消失。条带的裁剪矩形也要贯通整个画布高度，否则模糊的纵向外溢被切掉。
- **条带之间不能叠加，级数要够细**。叠加会把边缘重新叠硬：每级在实心右缘都贡献 50%，4 级合成是 1-0.5⁴ ≈ 0.94，而参考图该处是 0.50。级数太粗（试过 4 级）时每级交接处沿形状边缘鼓起一道脊——看上去就是「模糊底下还剩一圈轮廓」。64 级下每级 σ 只差 σmax/64，脊消失（实测沿弧边外侧 25px 的墨量全程单调，无回升）。

## 产物（exports/）

`deepdive-d-{fade,fade-soft,fade-tight}-1024.png` 与同名 `.svg`；
`deepdive-d-fade-{512,256,128,64,32,16}.png`（基准变体尺寸阶梯）。

已核（PIL 像素，基准变体）：中高度剖面与参考图逐点对齐（u=0.98 处 0.602 对 0.610、u=1.03 处 0.279 对 0.335、u=1.08 处 0.082 对 0.093；50% 落在 u≈0.985，比参考图的 ≈1.005 早约 1.5% 宽度）；三档变体沿弧边外侧 25px 的墨量全程单调递增、无回升（残影脊消除）；左侧圆角逐行最左墨点与理论弧一致（y-yT=20 处 145 对理论 144.7）；左边/顶边/底边在左半段保持 1px 硬边；墨迹距画布四边 ≥85px。

**尺寸可读性（实测）**：32px 起仍能读作实心 D；16px 糊成软块——右侧渐变模糊的本质所致，若要用在小尺寸位（菜单栏、favicon），需另出无模糊版。

## 重渲染

浏览器打开 `index.html`：`⬇ 导出全部 PNG` / `⬇ 导出全部 SVG`。定尺寸产物不必点击，无头 Chrome 直接截图：

```sh
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
"$CHROME" --headless --disable-gpu --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=1024,1024 --default-background-color=00000000 \
  --screenshot=exports/deepdive-d-fade-1024.png \
  "file://$PWD/index.html?mark=fade&size=1024"
```

`?mark=<变体>[&size=<边长>]` 是单标模式：整页只有该标记，截图尺寸即产物尺寸。SVG 版用 `--dump-dom` 取 `<svg>…</svg>` 再加一行 XML 声明。
