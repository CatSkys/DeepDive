> **品牌名：DeepDive（中文配对「深潜」；前身工程代号 DSHmini，工程改名收口见 `docs/BRANDING.md` §5）。** 本稿为 ASCII 鲸鱼 logo 的唯一事实源。
> **状态：已定稿（2026-09-02，用户确认"差不多"）。** 44 列大字符版为最终参数，种子 20260902。改动前先备份 exports/。

**ASCII 字符构成官方 DeepSeek 鲸鱼 · 黑色墨字 · 透明底资产。** 无实心鲸鱼打底、无背景色。

## 生成配方

1. **采样**：鲸鱼 path（官方 favicon.svg，50×50 viewBox）fit 到 1024 采样空间，做 mask + 两级高斯模糊（blur9 / blur30）
2. **逐格打分**（主视觉 44 列大字符，字符步进 = 格宽 × 0.62）：
   - 密度 `s = 轮廓带(blur9−blur30)×1.55×0.85 + 存在场(blur9)×0.34`，乘 `0.5+0.9×rand()` 纹理抖动
   - **强轮廓格 = 剪影骨架**：阈值 `edge>0.5`（≤48 列粗网格放宽到 0.42），仅 5% 随机断口，强制 `+ * x` 重字符、α≥0.82
   - **环身薄带**（edge<0.3 且 blur30<0.35；粗网格 0.24/0.28）直接舍弃 → 左侧叶形负形、嘴部镂空的边界才干净
   - 内部疏排 + 深处空洞 20%、一般 10%；`s<0.22/boost` 直接留白
   - **镂空点晕**：mask 外靠近边缘处 16% 概率撒 `.` `'`（把嘴/眼负形"显形"）
   - 每格子采样：粗网格（≤48 列）9 点、细网格 5 点（格心 + 环绕），细弯月不漏
   - 逐行随机错位 + 错版偏移（套印感）
3. **眼部签名**：官方眼点位置（viewBox ≈ 26.96, 24.6）固定一个 `#` 簇 + 四点
4. **墨色**：`#0b0b0c`，α 0.42–1 随密度浮动
5. **小尺寸补偿**：`boost = 1.7 − size/1024×0.7`（1024 不补偿），列数 `{512:30, 256:20, 128:14, 64:10, 32:8}`
6. **图标容器**：浅暖灰色域高斯模糊（blur 10.5%）+ 粗细两层颗粒噪点（overlay）+ 斜向光条 + 顶部反光 + 暗角 + 内缘亮线

## judge 验收结论（v2，10/10 通过）

- 透明/纯字符/黑墨确认成立；不会被误读为心形；疏朗度符合"密度少一些"的要求
- 两点程度提示（下一稿候选）：
  1. 中央特征偏弱——眼点/嘴线仅零散暗示；可加密眼位字符、左侧缝隙再让空 1–2 格
  2. 小尺寸衰减陡——256 为可读下限，128 起失认；<128 场景（Dock/favicon）建议单出一版简化小标（只留轮廓密排、去掉内部疏排与外围散点）
- 磨砂容器可选优化：上缘加一道更亮的斜向高光带，玻璃感更强
