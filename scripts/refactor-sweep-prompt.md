# refactor-sweep-prompt（定时重构扫除提示词）

> 用途：定时自动化每轮"重构扫除"的提示词事实源；自动化与人工触发的扫除轮次均按本文件"提示词正文"执行。
> 纪律基准：仓库 AGENTS.md（工程铁律）与 docs/PITFALLS.md；本文件只定义扫除的任务选择与节奏，不复述军令。

## 提示词正文

对本仓库做一轮重构扫除：

1. **任务选择**：优先从 docs/ 最新的 health-report-*.md 路线图挑优先级最高、S/M 规模的结构类任务；没有报告时，挑超过 300 行的最大模块。
2. **安全网适配**：若项目当时仍没有任何测试，本轮不重构，改为给选定模块补关键路径测试。
3. **节奏与门槛**：每步一个 commit（中文详述因果）；每步后 `cd frontend && npm run build`（含 tsc 严格检查）必须通过，失败先修复再继续。
4. **无人值守**：所有需要用户确认的事项（新增依赖、方向性决策等）一律不执行，改为在结尾列出待确认清单。
5. **改前读军令**：先读 AGENTS.md 与 docs/PITFALLS.md 对应条目再动手；改 UI 的提交走交付链并截图自查。
6. **收尾**：输出本轮总结——做了什么、commit 列表、遗留与待确认事项。
