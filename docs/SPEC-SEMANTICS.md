## 1. 一句话定位

> **按一下快捷键，一行输入开始一段工作（Ask Anything 单入口）；像 Codex 一样并行推进任务，随时打断、审查、纠正；一切数据留在本机。**

三个关键词：
- **唤起即用**：全局热键 → 焦点即输入框；一行输入 = 任务 / @引用 / 命令，默认值自动。
- **看得见**：全局任务侧栏（置顶/最近/时间）+ 并行运行；过程可折叠但可查；需要你时主动叫醒。
- **本机优先**：无账号、无云端；引擎是本地进程。

## 2. 对象模型 + 参考图语义映射

> 定位：**DSH 引擎定义语义**（每行"引擎来源"是事实）；参考图/Codex 的对应词汇仅为一致的 UX 参照。
> 实测依据：本机 `dsh --profile web --dump-config` + 已装包 `dsh-agent-presets` / `dsh-persona` / `dsh-skill` / `dsh-client-ui-agent-preset`。

| 参考图（Ask Anything 截图） | DSHmini 对象 | 引擎来源 |
|---|---|---|
| **Ask Anything 单入口**（标题+大输入框） | **Launcher Composer**：一行输入 = 任务/@引用/命令 | `ctx.sessions`、`commands`、`attachment` |
| **AI Agents 面板**（选择器） | **Agent Preset 角色**：通用设置「默认会话模式」卡片选定，**新建会话生效、创建即锁定**（`agent-preset-locked`，引擎拒绝运行中切换）；只开放 standard（标准）/ minimal（极简）两项 | `agent-presets` 设置命名空间 `default`、`agentPresets/list`、`agent-preset/selected` |
| **New Chat / Claude Sonnet 4.6**（右上） | **会话头**：标题 + 状态点 + **角色只读标签** + 模型名 | preset 摘要 + `ctx.llm` |
| **Memory 卡**（Work context / Personal context） | **Persona 与上下文**：persona 文本（工作上下文）、技能/上下文构成（个人上下文） | `dsh-persona`（`deployment:persona` section）、`dsh-skill`、system-prompt context providers |
| **侧栏**（Pinned / Recent / Last Week / April） | **全局任务侧栏**：置顶 + 最近 + 时间分组；工作区为筛选器（全部/某工作区） | `ctx.sessions` 列表、`sessions.fork`、workspace 注册表 |
| **Task 任务**（侧栏单元） | **Session 会话**（运行中=任务在干） | `session` 日志、`ctx.sessions` |
| **⟳ 重制 / ➤ 发送** | Composer 左=重置(重开任务)，右=发送（`arrow-up`） | 会话命令 |
| **search for actions…**（浮层底部） | **⌘K 命令面板**（CommandPalette，已实现）：见 `UI-SPEC` §命令面板 | `commands` 注册表 |
| **Agent 状态（「Maya…」人格）** | Persona 作为身份行 | `dsh-persona` |

客户端**自有**语义只有三个：**迷你面板**（快速入口，§6.1）、**主窗口侧栏**（任务一览）、**通知/注意力**（打扰规则）。

## 3. 会话生命周期状态机（= Codex 任务状态）

```
 [草稿] --发送--> [排队 queued] --> [运行中 running]
                                     │  ├─ 思考 thinking
                                     │  ├─ 执行中（工具→编辑→验证…）
                                     │  ├─ [等待审批]
                                     │  ├─ [等待回答]
                                     │  ├─ [等待计划确认]
                                     │  └─ [等待输入 needs-input]（同等待你）
                                     ├─用户打断 --> [运行中]（新消息继续）
                                     ├─完成 --> [已完成 completed]
                                     ├─停止 --> [已停止]
                                     └─错误 --> [失败 failed] --重试--> [运行中]
```

- **状态可折叠为五档**（侧栏/面板/通知共用）：`排队 · 运行中 · 等待你 · 已完成 · 失败`。
- **"等待你"是唯一主动叫醒语义**（Codex 同款）：审批/提问/计划确认触发通知+徽标，其余零打扰。
- 打断/审批/重试**不改变会话身份**；从历史任意消息点 **Fork** 出新任务（Codex checkpoint 语义）。

## 4. 交互语义

### 4.1 唤起
- `⌥Space`（可改）全局热键 = **会话面板窗的显隐开关**（2026-10-12 定稿：召唤目标是会话面板窗；药丸显隐与本体主窗都不受热键控制，主窗召唤走 Dock/菜单栏）；应用常驻菜单栏。

### 4.2 工作区语义（✅ D1 = Codex 式）
- **每个任务创建时显式绑定工作区**：选择器（最近工作区列表 + "选择文件夹…"）。
- 默认**记住上次选择**（最近项目优先），但工作区边界始终可见可改（顶部切换器、任务详情徽标）。
- 侧栏任务列表**按当前工作区过滤**；切换工作区即切换视图。
- 任务详情始终显示归属工作区；任务间跳转不丢工作区身份。
- **安全边界绑定**：**会话 cwd 即该会话的沙箱边界**（实测 `sandbox-policy.resolve({session})` 取 `session.header.cwd`，`session/create` 的 cwd 取 `workspace.path`）；引擎进程 cwd 只当没有会话上下文时的兜底根（agentless 调用）与 `@` 文件索引的扫描根。所以侧栏切换工作区只是换视图，不需要重启引擎。

### 4.3 主窗口语义（✅ D2 = Codex 式并行 + 参考图侧栏）
- **单主窗口 = 侧栏（任务列表）+ 内容区（会话视图）**；多任务**并行**同窗分列。
- **侧栏 = 全局任务列表**（参考图式）：`置顶`（用户 pin）→ `最近` → 时间分组（上周 / 4 月）；「新会话」入口是列表最后一行（Safari New tab 式，视觉细节归 UI-SPEC §3.2）；顶部**工作区筛选器**（全部 / 某工作区，默认全部）+ `+ 新建任务` + 搜索框。
- **新建会话 = 草稿页语义**（New Chat 式）：所有「新建会话」入口（顶栏 ＋ / 侧栏项目行 ＋ / 命令菜单）只切到草稿页（hero），**不发消息不产生真实会话**；首条消息发出时才经 `session.create` 创建，草稿页上选的模型随创建一并生效。启动同理：落在草稿页，不自动建/复用空会话。草稿页仍然能用 `@` 引用与 `/` 命令：`@` 的文件/会话候选走壳侧列举（单层目录 + 本地会话表，引擎索引需要 agent）、`/` 的目录走前端内建命令表（引擎 `commands/list` 的 `agentId` 必填），两者都是草稿页专属的兜底车道；**在草稿页用命令（菜单点击直发、或整行回车直发）会先建会话再派发**——与首条消息同一链路（建完即进该会话，草稿清除）。
- 侧栏每项：状态点 + **一句话标题（单行截断）**；waiting 任务 = 行高亮 + 白点呼吸 + 标题加粗。
- **会话头**（右上对齐，New Chat / Personal Assistant / Cl... 式）：任务标题 + 状态点 + **角色只读标签** + 模型名；agent 状态行（"编辑中…"）只在这里。**顶栏操作**：侧栏开关、重命名（✎）、Memory 入口（🧠）。
- 任务可**置顶/取消置顶**（pin，对应侧栏分组）；新建任务＝并行启动（并发跟随引擎：无硬上限，客户端不做二次排队）；需要你的任务侧栏计数。
- **⌘K 命令面板**（已实现，`frontend/src/components/CommandPalette.tsx`）：操作 / 项目 / 会话 / 设置分区四类统一搜索。
- P2：任意任务可 **detach 为独立窗口**。

### 4.4 输入语义（含 ✅ D6 附件 = P1 基础能力；Input-first 单入口）
- **一行输入收全部**（Ask Anything 哲学）：任务 prompt / `@` 引用（文件·会话·工具）/ `/` 命令——不预先选角色与工作区，默认值自动（记住上次），需要时再改。
- **角色选择（Agent Preset）**：新建任务时可选（chip 与工作区选择器并列，**staged 语义**——引擎要求创建时锁定，运行中不可切换）；会话头显示只读角色标签（New Chat / Personal Assistant 式）。
- 文本 prompt；**附件入口**：⌘V 粘贴图片 / 拖拽文件与图片 / **＋ 二级菜单**（截图 / 上传文件 / 添加文件夹… / 提及文件、对话或工具…，照 Atd 参考图，2026-10-13 定稿）。**一律胶囊，且胶囊插在正文里**（行内原子：附件在哪儿就落在哪儿，前后都能接着打字；图标 + 名 + 上传进度；就绪才可发送；**媒体文件悬停出预览画面**，仅限图片与视频）。发送载荷按文档序（正文段与附件段交替）。**没有大小上限**：图片 ≤ 32MB 随 prompt 内联直传（**图片→视觉路由**，模型不支持时改走文件回执、不丢附件），更大的图片与一切普通文件都按文件附件上传——页面手里有字节走 XHR（桥超缓冲上限落盘再转发），只有路径的（选择器挑的大文件）由壳按块读盘直送引擎。**文件夹**没有字节可传，转 `@` 引用（引擎宿主读盘，路径只有壳拿得到，见 PITFALLS §4.36）。**截图**（＋ 菜单第一项与全局热键 ⌘⇧2 同一落点）：壳里跑完整段采集（全屏冻结 → 拖选/点选 → 标注），回来的图与一份「屏幕上下文.md」按既有附件通道进胶囊（图内联、上下文按路径）。
- `/` 命令建议；无斜杠自然语言即任务本体。
- ❌ 不做应用启动器/计算器/翻译等非 agent 功能。

### 4.4bis 上下文与记忆（Memory 卡语义）
- **Memory 卡**（FloatingCard）：展示**上下文构成**而非解释文字——① Persona（工作上下文：persona 文本）② 上下文/技能（Personal context：skills、runtime context 快照来源→sandbox/approval policy 等）。
- 操作：编辑 persona 文本（写回 preset/persona 配置）；**重新生成**（P2：以 LLM 重写 persona 文本）；清空/恢复默认。
- P1 只读展示 + 编辑；重生成 P2（引擎无对应 API，属客户端增强，标注清楚）。

### 4.4ter 模型基准（能力数据三分家）
- 模型选择器详情卡里的能力与基准数据**三个家，一事一家**：**可用性**＝引擎目录（`session/modelCatalog`——能不能路由）；**能力事实**＝引擎目录投影（`inputModalities` / `contextWindow` / `reasoning`——引擎知道的）；**基准刻度**＝前端登记表 `frontend/src/modelFacts.ts`（速度/智能/成本 0–4——AA 榜与官方牌价的静态抄录，运行时零网络依赖）。登记表只放引擎不知道的刻度，同一事实不写两份。
- **全有或全无**（用户 2026-10-10 定稿）：速度/智能/成本三项刻度**齐了才渲染**；缺任一项（登记表未收录、或该行没抄全）只显「暂无基准数据」占位框，绝不出现"只有成本没有基准"的半张卡。上下文/能力行照常（引擎事实照给）；**引擎可路由性不因登记表改变**——选模型永远提交引擎目录里真实可路由的 id，登记表不构成目录快照。
- **一行一个模型，键是模型名本身**（用户 2026-10-14 定稿）：同一个模型走哪条路由都是同一个模型——能不能路由归引擎，刻度归登记表，所以表键不带提供方（查表前按 `benchKey` 归一：小写 + 取最后一个 `/` 之后那段）。网关给的 `<vendor>/<model>` 前缀（CommandCode 的 `zai-org/GLM-5.2`）与官方直连 id（`glm-5.2`）命中同一行；判据就是「同一模型在别家路由上分数一致」。成本不破这一条：引擎发价的行跟引擎，引擎发不了价的行（自定义端点、预置提供方——适配器把 0/0 滤成"未定价"）用表里的手抄档兜。
- 成本刻度方向：**越满越贵**（条长 = 花费量级，与速度/智能同向可读）。
- 填表口径（AA Output Speed / Intelligence Index 折刻度、官方牌价折成本、行尾留出处日期）见 `modelFacts.ts` 头注释；视觉规范见 `UI-SPEC §2.5 ModelMenu`。

### 4.5 观察语义（✅ D3 = C：折叠 + 异常高亮）
1. **对话流**（默认）：用户消息 + 助手回复；流式 markdown/代码块（内联复制按钮）。
2. **工具活动**：默认一行卡片（`⏱ bash · 3.2s · ⚠ exit 1`）；**错误/异常退出/大 diff 自动高亮**；点击展开输出与文件 diff（`+`/`-` 行）。
3. **轨迹层**（⌘T）：turn/step 时间线、消息序列、token 消耗、子代理活动（P2）。
- **Follow 语义**：默认自动滚到最新；上滚即暂停跟随，底部「回到最新」浮钮。

### 4.6 干预语义（全部为会话内操作）
| 动作 | 触发 | 效果 |
|---|---|---|
| 打断 | 运行时 Composer 右槽的停止按钮（无键盘打断：Esc 的语义留给「收起菜单/候选」） | 停止当前 turn，会话保持可继续 |
| 纠正 | 直接输入新消息 | 进入 inbox，下一步前送达 |
| 审批 | **WebView 内审批卡**（`session/Cards.tsx`）：允许一次 / 拒绝 | `approval` seam；引擎默认策略 `ask`（实测），`danger-full-access` 预设下 `never` |
| 回答 | 选项点击 / 自由输入 | `user-questions` seam |
| 计划确认 | 阅读→批准/修改后继续；以引擎 plan mode 为准（**默认关闭**，会话级开关） | `plan/mode` |
| Fork | 历史消息点 → 新建任务 | `sessions.fork`（P1 基础，P2 细粒度） |
| 重试/停止 | 失败态/会话菜单 | 引擎侧 |

### 4.7 会话管理语义
自动标题（引擎 title provider）+ 手动重命名；继续（原工作区原上下文）；归档/恢复/删除（删除需确认+提示导出）；导出 Markdown/JSONL（P1 简版，P2 全文转录）。
侧栏每条任务行行首带**置顶**钮（hover 显现、已置顶常驻；置顶会话独立成「置顶」组）。
**自动归档（设置·通用）**：开关 + 保留时长档（12 小时 / 24 小时 / 7 天 / 30 天，默认 7 天），
打开后按 SCAN_INTERVAL 定时扫描会话列表，把「已停止运行（已完成）、无未读、**未置顶**、
且最后更新时间早于保留期」的会话归档；当前正打开的会话不归档。**置顶即豁免归档**（用户定稿）。
开关默认**关**（opt-in）：本引擎 wire 面只有 `workspace/archiveSession`、没有反向方法，
归档在 UI 里不可撤销，故不默认开扫描。判定实现 `frontend/src/autoArchive.ts`（纯函数）+ 驱动 `useAutoArchive`。
**归档页（设置·已归档的聊天）**：按项目分组 + 计数、搜索、项目筛选；每行给「取消归档」（恢复，可逆）与「删除」（删聊天记录，不可逆，需确认），页头右上「全部删除」作用于当前筛选结果（一次调用一批 id）。
这两个动作都是**引擎 RPC、一次调用当场生效**（不重启引擎）：取消归档走 `workspace/unarchiveSessions`（幂等，恢复后回到它原本的位置），删除走 `session/deleteSessions`（一次一批，日志、投影缓存、归档集、工作区记账一起删）。
删除的判定在**引擎侧**：活着的（挂着或 agent 在跑）一律拒（`busy`），没有日志的回 `missing`，存储拒绝回 `failed`——逐 id 回原因，UI 据此说"跳过了几个、哪几个没删掉"。批次是部分的，一个失败不拖垮整批。前端不再持任何本地覆盖集（那层是为"引擎做不到"而存在的，已随实现删除）。纪律与三条不变量见 PITFALLS §4.15。

## 5. 通知与注意力语义

| 事件 | 打扰等级 | 形态 |
|---|---|---|
| 等待你（审批/提问/计划确认） | 🔴 高 | 系统通知（点击回任务）+ 侧栏高亮 + 菜单栏徽标 |
| 任务完成 | 🟡 中（默认开，可关） | 静默通知 |

### 6.2 划词与截图（2026-10-13 落地，Atd 整包移植）

**划词（选择文字工具栏）**：在任意应用里选中文字，浮出一条玻璃胶囊——**问 DeepDive**（把选中文字引用进输入框，不直接发送）+ 若干**划词命令**按钮（翻译 / 润色文字 / 总结 / 解释 / 提取待办事项 / 审查代码；超宽收进 More 菜单）。

- **浮出方式三档**：`按住 ⌥ 选字`（默认）/ `任何选中都浮出` / `监听模式`（连按两次组合键开合，开着时屏底一条状态胶囊说明）。设置 → 划词与截图里改。
- **触发**：全局鼠标抬起启发式（拖拽/双击/shift 点击）+ 150ms 去抖；**探测只问选区范围与位置，不读文字**（辅助功能 API），文字只在动作点下后读一次，读到即存进壳侧**暂存**（面板抢焦点之前——面板一聚焦，前台应用就换了）。
- **不抢焦点**：胶囊是永不取键盘的 `popUpMenu` 层面板，被选中的那个应用全程保有自己的选区；任意按键/滚动/点别处/切换应用即收。
- **排除**：安全输入框（密码）从不探测；设置里可按 bundle id 排除若干应用；本应用自身排除。
- **权限**：读选中文字需要**辅助功能**；未授权时工具条不装监听、不出现。设置页「划词与截图」两处权限都**显示状态**（已授权只显示「已授权」，不再摆按钮；未授权才给「打开系统设置」，深链逐格实测可用）。
- **动作落地**：「问 DeepDive」把文字引用进草稿，发送与否由用户决定；**命令**点了就发——亮起迷你面板，把这条命令的提示词连着你选中的文字当一条消息发出去，答案在面板对话里流式回来（发进面板当前会话，草稿页先新建一条并切过去；输入框里没发出去的草稿不受影响）。
- **划词命令**：每条 = 一个名字 + 一段提示词模板（`{{input}}` 处填选中的文字，没写就接在末尾）。内置 6 条（名字照 Atd 的 starter，提示词取它的英文原文；参数先取默认值——翻译目标语言简体中文、总结要点式、待办按负责人）。设置 → 划词与截图 → 命令里可加 / 改 / 停用 / 删除，也能一键恢复内置。**与引擎的 `commands/list` 不是一份**：那几条（`/compact`、`/permission`、`/plan`、`/feedback`）是本地工具命令，在输入框的 `/` 菜单里，不上胶囊。

**截图**：输入框 ＋ 菜单的第一项、迷你面板的相机条目、全局热键（默认 **⌘⇧2**，可改键/可关）三个入口同一落点。

- **采集**：ScreenCaptureKit **逐屏冻结**（光标所在屏先冻，自家窗口从图里排除）→ 每屏一层 `.screenSaver` 级 overlay，交互落在冻结图上（所见即所截）。
- **选区的样式（2026-10-13 用户定稿）**：**遮罩式**——选区之外整屏压暗（黑 40%），边界只是两条发丝线（内侧白 85%、外侧黑 35%，亮底暗底都读得出），手柄是白点 + 深灰描边。**截图这一族不用强调色**：不跟随系统蓝色（工具选中态是白底黑字形、确认钮是白字形、放大镜与画布手柄同黑白灰），因为它浮在别人的屏幕上、不该带本应用的品牌色。
- **选区交互**：指针下的界面元素自动高亮、单击即选；拖拽自由选；滚轮在「元素 → 窗口 → 整屏」之间升降；`W` 只认窗口、`R` 复用该屏上次的区域、`⌘A` 整屏；选区随时可移动/缩放（方向键微调、⌥+方向键缩放）。**放大镜**跟随被调的边角并读像素色值。
- **标注**：11 件工具（选择/矩形/椭圆/箭头/直线/画笔/荧光笔/文字/马赛克/聚光灯/序号），单字母快捷键；马赛克三态=**马赛克块（逐块均值）/模糊/纯黑遮盖**（遮盖是唯一保证遮死的形态，注释里写明均值块可被反推）；序号徽章按文档内位次自动重排；撤销按整文档回滚、滑杆与滚轮连动并成一档。标注锚在屏幕上——选区移动只改导出范围。
- **产出**：确认后 → 图片（长边 2560、PNG 优先、超 8MiB 转 JPEG 并逐级缩）与一份 **`Screenshot … context.md`**（App/窗口/选中元素 + Vision OCR 识别出的屏幕文字，12k 字符帽）成对进输入框；另有「复制」路径直接进剪贴板。存盘在 `<support>/screenshots/`（保留最近 40 张）。
- **权限**：**屏幕录制**；每次截图前现查（授权被吊销的构建只会截到壁纸），未授权时提示并可跳到系统设置。**刚授权的进程要重启才生效**：预检已过而采集起不来时，界面明说这一点（不再静默）。
- **权限**：屏幕录制（截图）与辅助功能（划词）两项按「bundle id + 签名身份」记；交付链的 Developer ID 重签让授权跨构建保留（PITFALLS §11.2）。

## 7. 首次运行语义（Onboarding）

已实现（`frontend/src/onboarding/`，取代旧的首启欢迎页）：引擎连上后，若正向确证「一个密钥都没配」则盖一张**四步引导卡**；每一一步都可以跳过，进度落在壳偏好 `deepdive.onboarding`。

1. **迁移**：检测其他 Agent 的会话（dsh-chat-import 插件面板路由）与模型配置（壳读白名单配置文件原文 + 前端显式映射表），一次点击导入；表外来源如实标"不支持"，不猜。
2. **配置模型**：填密钥（默认 DeepSeek official，落 `credentials/set`）→ 选一个默认模型（写引擎 `agent-default-model`）。其他提供方引导结束后在设置→模型里加。
3. **新建项目**：建第一个项目空间（＝工作区；壳建目录 + 引擎注册），表单在卡内，编排与「新建项目」弹窗共用一份实现。
4. **开始使用**：结尾语只讲怎么发消息（输入框回车 / `@` 引用 / `/` 命令 / ⌥Space），不做实际引导——第一条消息由用户自己发（发送才建会话）。
5. 出现条件：没密钥必出现；有密钥后只在"走到第 2 步之后且未跳过/未完成"时续显——有密钥有项目有会话的老用户不会被弹。
