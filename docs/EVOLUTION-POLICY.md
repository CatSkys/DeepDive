# EVOLUTION-POLICY — 自进化提案政策（可演进）

> **本文件是「什么值得沉淀、能写到哪里、怎么落地、怎么算有效」的唯一事实源**，也是二级进化的对象：改这份文件同样走"提议 → 机械门 → 自动落地"。
> 设计语义与出处见 `docs/SPEC-SELF-EVOLUTION.md`；各知识家的写作规范归它们自己的文档（`AGENTS.md` 的维护条款、`docs/PITFALLS.md` 的条目格式）。
> 协议与触发判据（怎么输出、什么时候提）归引擎技能 `deepdive-evolution`，本文件只写"标准与红线"。

## 0. 自治模型（零人审）

**自进化的"自"= 人的干预压到最少**（MiMo Dream/Distill 全自动；penguin 的 Edit 落库无审阅；EverOS 无写入门控）。人只做两件事：

1. **批准政策**（一次性）：设置→自进化 的总开关即政策批准，确认框写明自动化范围；
2. **事后审计**（随时）：设置页台账看流水、丢弃/撤销、查看证据原文（EverMe `read_original` 界面等价）。

单条经验的生死全部由**机械门**判定（下 §3），不设采纳按钮。信任来源 = 允许清单 + 写前机械门 + 写后机械验证 + 回滚完全且便宜（Cordis 可逆效应 / git 谱系）。

## 1. 允许清单（能写到哪里）

| home | 目标文件 | 什么样的经验进这里 |
|---|---|---|
| `agents` | `AGENTS.md` 的规则区 | 跨会话常驻的**行为规则**（1-3 行 + 链接到它的家） |
| `pitfalls` | `docs/PITFALLS.md` | 真实事故：症状 + 根因 + 处置 + **诊断锚点** |
| `spec` | `docs/SPEC-*.md` 的设计段 | 产品 / 协议语义边界的确定 |
| `skill` | 引擎技能正文 `SKILL.md` | 可复用的操作流程（黄金路径，含走过的死路） |
| `policy` | 本文件 | 提案策略本身（判据 / 阈值 / 清单） |
| `global` | `$DSH_HOME/AGENTS.md` | 跨工作区常驻的全局经验（锚点固定 `## Agent Added Memories`，AHE 惯例；无 git，担保弱于仓库内——只有写边界 + 审计 + 整理环清理） |
| `plugin` | `$DSH_HOME/deepdive/plugins/<id>/index.js` + `profiles/web/cordis.patch.yml` 挂载块 | 能力层进化：Cordis 引擎插件（工具/中间件），锚点 = 挂载 id |

代码、脚本、配置（产品代码）**一律不在允许清单内**；`plugin` 家写的是引擎扩展（AHE 组件分层里的 tool implementations 一层），不是产品代码。

## 2. 类别与判据（什么算值得提）

- `incident` **事故**：真实踩过、有可复现症状的坑。同一坑出现第二次 → 必提。
- `workflow` **流程**：试错数轮才走通的路径。**连死路一起记**——"下次别再试 Y"常常比成功本身值钱。
- `fact` **事实**：非显然的项目事实（凭据在哪、怎么验证线上、这条流水线的隐藏前置）。
- `rule` **规则**：应当常驻的行为约束（进 `AGENTS.md`）。

**不值得提**：一次性任务的细节、实现结果、助手的自我总结、"用户没有再提到"这类推断。

## 3. 机械门（写前全机检，模型不在环内）

每条 pending 提案在自动落地前过两道壳侧机械门（`lesson-gate.mjs`，宿主直跑——Ditto selftest：宿主验证，不采信模型）：

1. **证据逐字**：≥1 条摘录逐字出现在 origin 会话日志（解码后的事件字段值）里——EverMe 内容哈希核原文的宿主等价物；
2. **锚点存在**：目标文件里有锚点标题（`global` 家恒过——文件由落库创建；`plugin` 家改查 id 形状 + patch 文件在 + 未重复挂载）。

任一不过 → 状态直接退役（`expired`）留档。另两道门在流程里：**写入边界**由沙箱执行（落库会话 cwd = 落点作用域根，workspace-write），**速率上限**见 §6。

## 4. 落地与效果主张

- 落库：过门即自动派发（每日上限见 §6）。agent 按锚点原样写入 + git 提交引用提案 id（仓库家）；DSH_HOME 家写文件不提交。
- **落地确认**（`lesson-land.mjs`，宿主直跑）：不采信 agent 口头"完成"。仓库家 = `git log --grep=<id>` 找到那次提交 **且** `git show` 触碰文件 ⊆ 该家允许清单 **且** 目标文件含正文；DSH_HOME 家 = 文件含正文；`plugin` 家 = `node --check` 语法通过 + 挂载块带提案戳。失败分支：触碰文件出允许清单 → 自动撤销；内容缺失 → 重试额度内打回重落、超限退役。
- 效果主张（提案必须可被证伪）：
  - `metric: repeat-incident` —— 可 grep 的签名（提出前自证命中）+ 观察窗；
  - `metric: steps` —— 同类流程的匹配签名 + 观察窗；
  - 给不出可量主张的 `predict: null`：风格类，**不进效果统计**。
- **到期校验**（`lesson-verify.mjs`，宿主直跑，模型只出数）：按事件时间把签名命中归入「落地前 / 落地后」两个等长窗口，窗口从 **appliedAt（采纳时刻）** 起算——政策口径是"落库时切两半"，createdAt 是提议时刻不能当基线。判定由应用按阈值算：

  | 指标 | 有效 | 无效 | 样本不足 |
  |---|---|---|---|
  | `repeat-incident` | `after ≤ before / 2` | `after > before / 2` | `before == 0` |
  | `steps` | `after ≤ before × 0.7`（≥ −30%，匹配会话的**均值**口径） | `after > before × 0.7` | `before == 0` |

- **无效即撤**（penguin「再评估不提升才保留」的执行面）：判无效 → 应用自动派发回滚（仓库家 git revert；DSH_HOME 家删节/摘挂载块）→ 状态退役留档。
- 反作弊：校验数据只认日志 / git，不自评；风格类不进统计；签名须自证可 grep；样本不足不写成败。

## 5. 运行参数（默认值，可改；改它=二级进化）

| 参数 | 默认 | 出处 |
|---|---|---|
| 复盘触发 | 距上次 ≥24h 且有会话更新 | 本地适配（复盘是一整轮 agent，比无工具学习贵，SPEC §9.0.4） |
| 复盘静默兜底 | 7 天没复盘也跑一轮 | MiMo Dream/Distill 固定节奏 |
| 整理环 | 每 7 天一轮（去重/失效锚点/压缩，按作用域两轮） | MiMo Dream |
| **自动落地限速** | **每日 ≤3 条**（过门 FIFO） | dsh-evolve-modes 学习批次默认 3 |
| 落地失败重试 | 最多 2 次派发，超限退役 | 重试有界，不无限烧 |
| 到期校验重派间隔 | 30 分钟（回执丢失守卫） | P0 修复的护栏 |
| 校验窗口 | 14 天（从 appliedAt 起算） | dsh-evolve-modes 默认 |
| 模式 | 全自动（Propose 语义由机械门承载） | penguin/EverOS/MiMo 一致：进化本身无人审 |
| 总开关 | 默认**关**（设置→自进化，知情确认） | SoL-Pi 机制 opt-in |

## 6. 会话记忆（设置→记忆；与自进化并列的另一半）

Session 层记忆由随应用铺设的引擎插件 `deepdive-session-memory` 承载：每轮开始注入会话笔记（`<session_memory>` 围栏 = 不可信历史证据，EverOS 同款），模型用 `memory_note_write` 整份重写（字段规范在技能 `deepdive-session-memory`），`new_context` 走引擎压缩通道。fail-open：任何失败只记日志，绝不挡用户轮次。笔记落 `<DSH_HOME>/deepdive/memory/<sessionId>.md`，用户可查看/单条忘记/全部清除（Ditto 记忆页）。跨会话情节召回（Recall 层）由 EverOS 官方 dsh 插件承载（`uv tool install everos==1.3.1`，提取端点 DeepSeek；隐私边界见其 README——轨迹含源码片段，勿用于敏感仓库直到知晓后果）。
