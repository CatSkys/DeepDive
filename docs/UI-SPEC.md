> 上游：语义层 `SPEC-SEMANTICS.md`（对象与交互）→ **本文档**（视觉与呈现）→ 实现（React 组件 + 原生外壳）。
> **状态（2026-09-03）**：自建前端已全量落地（套壳时代结束），本文档是**现行视觉规范**；原「P1=套壳、组件库 P2 再做」的范围界碑已失效。后续新增界面以本文档为准。

> 由代码生成 ① CSS Variables（Web） ② Swift 常量（原生）。**任何一端手写数值即违规。**

## 0. 设计原则

1. **快（Fast）**——主流程 ≤2 次按键；快捷键永远可见（操作栏右侧键帽）；面板即焦点即输入。
2. **简单（Simple）**——一屏一个重点（输入框 / 会话流）；无装饰性内容；状态一眼可读。
3. **愉悦（Delightful）**——动效只出现在"发生"的地方。
4. **原生感 = 行为为先**：无 `cursor:pointer`、无 hover 高亮；设置独立窗口；弹层原生可越界；面板 vibrancy 透出材质；无白帧。
5. **一致（Consistency）**——一套 token、一套组件；组件均为 `@dshmini/design` 统一库导出。
6. **黑白（Monochrome）**——主题色只有黑与白（表面对应灰阶、亮度差）；**无强调色**。状态表达靠**符号 + 亮度**，不靠颜色：
   - 等待你 → 白点 ⚠ + 行整行亮度选中 + 呼吸；失败 → ✕ + 行高亮；完成 → ✓（灰）。
   - 彩色仅允许一处：**diff 增删**的绿红（内容层语义色，非主题色；如评审不同意可去除，改为 +/− 符号）。
7. **少字（Anti-Copy）**——文案规则见 §1.9：一切解释性小字、副标题、状态说明＝冗余。一行话能表达的，绝不用两句；一个词能表达的，绝不用一句。

### 1.5 材质与 Vibrancy（近黑玻璃）

- 面板窗口：`NSVisualEffectView`（material `.sidebar`/`.hudWindow`，Blending `.behindWindow`）＋ 透明 `WKWebView`。
- Web 侧表面色用 1.1 半透明值透出材质；不得写不透明色板。
- 玻璃细节：`surface.raised` ≥62% + `border.gloss` 顶部高光 + `shadow.floating`。
- macOS Tahoe：跟随系统 Liquid Glass；只组合系统属性。

### 1.6 图标（组件库已锁定：Lucide）

- **唯一图标源：Lucide**（MIT，`lucide-react`；参考图同款纤细线性风格）。
- **全局样式固定**：`strokeWidth = 1.5`（纤细）、`strokeLinecap/Linejoin = round`（柔和圆角）、`fill = none`、**单色 `currentColor`**。
- **尺寸阶梯**（唯一允许）：14（行内）· 16（列表 leading）· 20（卡片头部/工具卡）· 32（空态）；渲染用 SVG，`width/height` 由 token 控件。
- **颜色规则**：`text.secondary` 默认；激活/选中 `text.primary`；`waiting/failed` 状态图标 `text.primary`（黑白+符号语义，无彩色图标）。
- **封装**：所有图标经 `UiIcon`（`@dshmini/design`）使用——统一 stroke/size/color/命名；**禁止**直接 import 其它图标库、emoji 冒充图标、混合来源。
- **原生侧同源**：Swift 外壳用 SVG→`NSImage`（template）渲染同一 Lucide 资源（打包 SVG 资产）；不使用 `NSImage(systemSymbolName:)` 或其它图标集（系统控件自身的关闭/缩放红绿灯除外）。
- **SF Symbols 例外**：仅限系统自带控件行为（窗口控件、NSMenu 系统项），不用于业务图标。
- **插件图标底座例外（2026-09-17 用户定稿，照参考图）**：插件页（设置 → 插件）每行的 leading 是**彩色圆角方块**（32px、圆角 8、色相由模块名派生且恒定、内嵌模块名首字母）。插件是 npm 包、没有自己的图标资产，用色相方块替代参考图里的品牌图标以便一眼辨认。**这是 §6「拒绝清单」里"品牌色/彩色"的唯一例外、只限这一处**——方块之外的一切（开关、状态点、文字、按钮）仍守黑白。

### 1.7 动效

| 场景 | 时长/曲线 |
|---|---|
| 控件态 | 120ms `cubic-bezier(.2,0,0,1)` |
| 面板显隐 | 200ms：alpha ＋ scale .98→1 ＋ translateY 8→0；隐 120ms 逆序 |
| 浮层 | 160ms：scale .96→1 ＋ alpha；遮罩 160ms |
| 流式文本 | 无逐字动画；上插淡入 ≤120ms |
| 状态点 running/waiting | 呼吸 1.2s；`prefers-reduced-motion` 全静止 |

### 1.8 键帽（KeyboardHint）

字体 `xs`/500；圆角 6；底 `surface.input`；描边 `border.default`；内边距 3×5；顺序 `⌥ ⌃ ⇧ ⌘`（`⌥Space`）；英文键大写。**仅显示于操作栏与需要学习的动作旁，不解释。**

### 1.9 文案规则（Anti-Copy，评审 gate）

1. **没有解释性文字**：每个文案只有一个职责（标题/动作/占位/分组标签），无副标题、无说明句、无"以下""你可以"。
2. **动作动宾开头**：`+ 新建任务` `重新生成` `导出`——不加感叹号、不加"体验/敬请/让…更"。
3. **占位符即语法提示**：一条放完 ─ `输入任务，@ 引用 · / 命令`；不追加第二行说明。
4. **小字密码**：12px 及以下只作分组标签（Pinned / Recent / Last Week）、键帽、浮层小标题（AI Agents）；**禁止** 副标签/状态说明/时间戳弱化注脚出现在行内（时间仅主窗头部一处，见 §3.2）。
5. **分组标签词首大写**（Pinned · Recent · Last Week · AI Agents，与参考图一致）；中文场景用两字词（置顶 · 最近）。**标题一律单行截断**（…），完整标题在 P2 由原生 tooltip 展示。
6. 空态只一句：`还没有任务`；错误只一句：`引擎启动失败`（详情进日志，不在 UI 解释）。
7. **已登记例外（2026-09-17，用户定稿）**：插件页（设置 → 插件）标题下保留一行副标题「管理插件、技能和 MCP」——该页的 tab 条只露「插件 / MCP / 技能」三个词，副标题承担"这一页管什么"的范围说明（照参考图）。**其余分区仍然无副标题**；新增例外必须在这里逐条登记。

## 2. 组件规范（`@dshmini/design` 统一库）

> 纯展示 + 最小回调；无 hover 态；键盘焦点可见（**黑/白 2px 环**）。P1 每组件有 dev 预览页。

### 2.2 消息规范（两类，严格独立——用户定稿，2026-09）

> 用户消息与 Agent 消息是**两个完全独立的组件与规则**：不同的组件（`UserBubble` / `AgentMessage`）、不同的 class、不同的视觉规范。**禁止**用共用容器 + 子类差异实现；任何"消息系统"级别的一刀切调整都是违反规范。

| | 用户消息 `user-bubble` | Agent 回复 `agent-message` |
|---|---|---|
| 形态 | **降量显示**的气泡（克制、弱层）：小字号 `base`、半透 α .07、弱边框/弱内高光、圆角 14、61% 最大宽、右对齐 | **无气泡、无任何元素背景**：纯文字（`base`/21 白 93%）+ Markdown 层级 |
| 定位 | 弱于正文（不抢戏） | 主视觉通道 |
| 背景 | 半透明单层（无模糊） | `background: transparent`（元素与全部伪元素强制透明） |

> 此前的错误：两者共用 `.msg` 体系、气泡参数与 emoji/信息混调——已按"独立两套"重构并清空 `.msg` 残留。

### 2.2bis 悬浮层统一规范（FloatingPanel）

### 2.4 弹层材质 / 品牌图标 / 设置卡片（2026-09 定稿，来自模型页事故）

- **弹层材质**：`background: var(--panel-strong)`（.92 毛玻璃底）+ **自带** `backdrop-filter: blur(40px) saturate(160%)`。禁止恢复全局 `* { backdrop-filter:none !important }` 核弹 + 白名单机制——压缩器会把"标准 + `-webkit-`"属性对合并成仅 `-webkit-`，不同引擎静默失效，且 CSS module 类进不了 theme 白名单（PITFALLS §1.8）。新弹层自带 blur 即可；`.flow *` 的禁用保留（合成隔离，弹层不挂 flow 内）。
- **品牌图标（提供方 logo）**：全部**单色反白**（`fill=currentColor` 随主题），禁品牌彩色、禁白底/彩底 chip。来源顺序：`@lobehub/icons-static-svg`（AI 提供方全覆盖，`?raw` 内联 svg）→ `simple-icons` 单色 → 首字母 monogram。**禁用 React 内联 style 传 `maskImage`**——存在静默丢弃，`?raw` 内联 svg（自带 fill=currentColor）最稳（PITFALLS §1.9）。
- **卡片 vs 描边（用户定稿，2026-09-12）**：**有底色的卡片一律不描边**；确实需要描边的（贴边浮层等），**里外颜色必须一致**（描边只勾边、不换底）；流内**提醒条两端做胶囊**（`radius.bubble` 24，勿用 999px）。
- **分组卡片**：卡片**无描边**，纯底色区分范围（`var(--fill)`）；行间分隔线用缩进 `::before`（左对齐文本、右留空），**禁全宽横线**；区块标题与内容间距 ≥12px（标题贴内容为反复出现的回归）；**页面头已有大标题时，卡片内不再重复同级标题**（2026-09-04 快捷键页"快捷键"×2）。
- **Meta 胶囊与数值**：标签胶囊只呈现引擎真实数据（reasoning / 额外输入模态 / 上下文窗口），缺的属性不编造；`text` 是每个模型的默认能力、不占标签，模态来源字段 pi 是 `input`、DeepSeek 是 `inputModalities`（别互相代用）；数值紧凑化（1000000→1M、131072→131K）。
- **模型弹窗（2026-09 定稿，照参考图）**：字段面＝提供商 → 接口地址（自定义）→ API Key → 模型名称 → 高级配置（提供方 ID / 协议 / 视觉）；说明只留真正改变行为的那一条（模型名称下方「留空则添加该提供方的全部模型」），且写成一句软件提示、不写「A＝X；B＝Y」式规格口气，能从界面自明的（按接口地址推导的名字摆在占位里、协议有默认值）不再写一行解释；不出上下文窗口与显示名称，模型类型只给引擎真能兑现的「视觉（图片输入）」。
- **新建项目弹窗（2026-09 定稿）**：**壳、字号、控件规格与添加模型弹窗完全同源**（复用 SettingsRows 的 modal/rowGroup/rowCard/按钮类——标题 `lg`、输入 30 高 `base`、按钮 28 高；自定大字号被否决），字段面＝名称（必填，行尾内嵌图标触发钮）→ 审批模式 → 工作区文件夹（textField 同规格按钮「＋ 选择目录…」）→ 项目指令（可选 textarea，说明并入标签旁 ⓘ）。审批行绑定**应用级**设置（引擎 `permission.defaultPreset`，与设置页同源同义；引擎未提供时隐藏）——项目级化需引擎扩展，另行立项。工作区文件夹留空由壳在 `~/Documents/DeepDive Projects/<净化名>` 自动建（引擎 workspace/create 要求目录已存在，建目录只能壳做；撞名追加序号）；名称与目录末级名不同才走 workspace/rename；指令由壳写入 `<项目>/AGENTS.md`（引擎按 cwd 读），已存在不改动。图标选择器＝搜索行 + lucide 精选集（~46 个，含「默认（首字母）」复位项），portal 菜单复用 `.ddMenu/.ddItem` 配方（显式 min-width 压掉类的 `min-width:100%`）、放不下向上翻；选择按 workspaceId 存 localStorage（`deepdive.ws.icon.<id>`，桥端口已固定），显示优先级 glyph > 根目录约定图标文件 > 首字母，删除工作区同步清 key。浏览器（无壳桥）降级＝工作区文件夹手输路径（promptDialog）、指令字段不出现。

- 轮尾**交付文件卡**（官方 ui-deliverables 移植，`deliverables/presented` 事件）：与产物 lane 同标签+行布局，`交付` 标签后跟卡片——图片以内联缩略图（92×68，对齐已发送侧图片附件规格）呈现、点开应用内预览，其余是「文件名 + 描述」chip（点开预览；`data-file-ctx` 使其同样吃上一条的右键菜单）。相对路径按**会话 cwd** 解析（引擎口径）。
- 设置（v3 变更，用户拍板）：**内置于主窗口**——左导航 + 主区内容（与主界面同一 .sidebar/.main 底板与语义变量）；分区=通用/模型/自动化/导入/审批/快捷键/已归档的聊天/数据/使用统计；黑白。（原"480×600 独立原生窗口"方案废弃。）

## 4. 平台惯例验收清单（每条 = 发布 gate）

2. 设置页内置主窗口（v3 变更，原"独立窗口"gate 废弃）；弹层 P2 原生可越界。
